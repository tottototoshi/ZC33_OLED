# スマート時計＆温湿度計 取扱説明書

## 1. 概要

本機は、インターネット経由で正確な時刻を取得し、現在地の温度と湿度を同時に表示するスマートデスクトップクロックです。
初回起動時やWi-Fiルーターの変更時には、スマートフォンから簡単にネットワーク設定が行えるスマートセットアップ機能を搭載しています。

---

## 2. 起動とWi-Fiの初期設定（初回のみ）

初めて電源を入れたときや、保存されたWi-Fiが見つからない場合は、以下の手順で初期設定を行ってください。

1. **電源を入れる**
    本体に電源を入れると、起動ロゴが表示されます。過去に接続したWi-Fiを約60秒間探索します。
2. **設定モードへの移行**
    Wi-Fiが見つからない場合、自動的に「設定モード（Wi-Fi Setup Mode）」に切り替わり、画面に以下の情報が中央揃えで表示されます。
* `SSID: ESP32_Setup` （接続先の名前）
* `IP: 192.168.4.1` （設定画面のアドレス）


3. **スマートフォンで接続**
    スマートフォンのWi-Fi設定画面を開き、「ESP32_Setup」という名前のWi-Fiネットワークを選択して接続します。
4. **パスワードの入力**
    接続すると自動的に設定画面（ブラウザ）が開きます。
    「Configure WiFi」を選択し、一覧からご自宅のWi-Fi（SSID）を選び、パスワードを入力して保存（Save）してください。
5. **設定完了**
    設定が完了すると本機が自動的に自宅のWi-Fiに接続します。画面に「Connected!」と接続先の情報が3秒間表示された後、通常の時計画面へ移行します。

> **※注意**
> 設定モードのまま**120秒**操作しないと、自動的に再起動して最初から接続をやり直します。

---

## 3. 通常時の動作（2回目以降）

一度Wi-Fiを設定すれば、2回目以降は電源を入れるだけで自動的に接続します。

* 接続待機中は「起動ロゴ」が表示され続けます。
* 接続に成功すると、画面中央に「Connected!」と現在の「SSID」「IPアドレス」が3秒間表示されます。
* 万が一ルーターの電源が落ちている等の理由で繋がらない場合は、60秒後に再び上記「2.」の設定モード（Wi-Fi Setup Mode）に入ります。

---

## 4. 画面の見方

通常モードでは、画面全体を使って以下の情報が表示されます。

* **上段（温湿度）**
* `temp`: 現在の温度（℃）
* `humid`: 現在の湿度（%）
* ※センサーの数値をより正確にするため、約20秒（10回の読み取り）ごとに平均化して画面を更新します。起動直後は測定中のため「--」と表示されることがあります。


* **中段（カレンダー）**
* `月 / 日 (曜日)`


* **下段（時計）**
* `時 : 分 秒` （大きな文字で時刻を表示します）
* インターネット上の標準時計（NTP）と常に同期しているため、時刻合わせは一切不要です。



---

## 5. トラブルシューティング

* **Q. 画面に「Wi-Fi Setup Mode」と出て時計が表示されない**
   A. ご自宅のWi-Fiルーターの電源が入っているか確認してください。ルーターを買い替えた場合は、スマホから再度Wi-Fiの初期設定を行ってください。
* **Q. スマホでESP32_Setupに繋いだが、設定画面が自動で開かない**
    A. スマートフォンのブラウザ（SafariやChrome）を開き、アドレスバーに「 `192.168.4.1` 」と入力して検索すると手動で開くことができます。
* **Q. Wi-Fi設定を最初からやり直したい**
    A. 現在接続できているルーターの電源を一時的に切ってから本機の電源を入れると、60秒後に設定モードに入ります。


---

## 6. ハードウェア仕様（開発者向けメモ）

* **マイコンボード**: ESP32-C3 Super Mini
* **ディスプレイ**: 256×64 ピクセル OLED（SH1122ドライバー、SPI接続）
* **温湿度センサー**: DHT22（ピン7に接続）
* **主な使用ライブラリ**: `WiFiManager`, `U8g2`, `DHT sensor library`
